How visual features are built

Visual clusters group bikes by appearance. Each photo is run through YOLOv8 (detect the bike) → SAM (mask it) → composite on white & crop; that crop is embedded with CLIP into the vector the visual cluster map clusters on.

How missing specs are filled from descriptions

Tabular clusters group bikes by structured spec_* columns. When Allegro's parameter box leaves a column empty, the spec backfill sends the cleaned description to a local LLM (qwen2.5) inside the prompt shown below, asking it to extract every known field — and normalises what it finds into the spec_* columns that join the tabular cluster map's vector.
